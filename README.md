LUQER PRO 🎸
Precision Magnetic Thickness Mapping System for Luthiers
Luqer Pro is a professional-grade ecosystem designed for non-destructive thickness measurement of musical instruments. By combining high-precision magnetic sensing hardware with a powerful digital mapping suite, Luqer allows luthiers to visualize and document the graduation of spruce tops, backs, and sides with sub-millimeter accuracy.

🌟 Key Features
📊 Professional Topographic Heatmaps
The included Luqer Mapper Pro software uses Inverse Distance Weighting (IDW) to predict thickness across the entire instrument surface, generating smooth 5-color gradients (from thinnest Blue to thickest Red).
⌨️ "Hold & Send" Integration
The Luqer hardware acts as a Native USB HID Keyboard. With one click of the physical button, the precise 2-decimal measurement is "typed" directly into the digital report or any spreadsheet.

💻 Software: Luqer Mapper Pro
The software is provided as a Standalone Portable Windows Application (.exe) and a lightweight HTML/JS file.
Offline Ready: Works 100% without an internet connection.
Instrument Tracing: Custom boundary tracing with Cardinal Spline smoothing.
Advanced Navigation: Infinite Zoom (point-to-cursor) and Smooth Pan.
CAD Exports: Export outlines as DXF (R12) or SVG for use in Fusion 360, AutoCAD, or CNC carving.
Pro PDF Reporting: Generates formal workshop documents including:
High-res instrument map with heatmap overlay.
Project metadata (Model, S/N, Technician).
3-column data table supporting 90+ measurement points per page.

🔧 Hardware Features
Unibody Design: Sleek, ergonomic 3D-printed housing with a hand-polished tip.
OLED Display: 128x32 high-contrast screen with 180° rotation support.
Smart Sleep: Automatic OLED protection after 60 seconds of inactivity; wakes instantly on movement.

🚀 Quick Start
Connect: Plug the Magtune into your PC via USB-C.
Open Mapper
Map: Import a photo, trace the outline, and start logging points by clicking the image and pressing HOLD on the device.
